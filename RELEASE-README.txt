对话记录 —— 使用说明
================================================================

这是一个录 YGOPro 对局聊天记录的小工具。不联网上传，
所有文件都在你自己电脑上处理。不需要装 Node.js 之类的东西。

它有一个安装程序，装完之后双击桌面或开始菜单里的图标就能用。

----------------------------------------------------------------
先看这里：怎么开
----------------------------------------------------------------

  「yrp-tools 对话记录」  ← 桌面或开始菜单里的图标，双击它。

双击之后会开出一个**独立窗口**，不经过浏览器、也不会弹黑窗口。
录、看、导出、把本机录像拖进来，全在这一个窗口里。

窗口右上角的 × 就是退出。**不需要再去哪里点「退出界面」** ——
关掉窗口，后台的录制脚本会一起停掉。

日常流程：双击 yrp-tools.exe → 点「启动代理」或「开始记录」→
打完之后在同一个窗口里勾选录像、导出 → 关窗口。

服务器地址默认是：代理 mygo.superpre.pro:888、观战 mygo2.superpre.pro:888，
第一次打开直接点「启动代理」或「开始记录」就行。要连别的服务器就把它改掉。

----------------------------------------------------------------
几件用得着知道的事
----------------------------------------------------------------

  录制中关窗口     会问一句「还在录，退出会停掉录制」。
                   已经录到的内容不会丢（每条对话都是当场落盘的），
                   但没录完的那部分不会再记下来。确认了才会退。
                   没在录的时候点 × 直接退出，不弹任何东西。

  再双击一次       不会开出第二个窗口，而是把已经开着的那个窗口
                   提到前面来。两个窗口会抢同一批录像文件，所以只能有一个。

  装在哪           安装程序会让你选目录，装到哪儿都行。
                   录像和设置**不**放在安装目录里（见下一节），
                   所以装哪都不影响你的录像，卸载也不会带走它们。

----------------------------------------------------------------
录下来的东西在哪
----------------------------------------------------------------

都在 %APPDATA%\yrp-tools\ 里面（第一次运行才会出现）：

  replays\            录好的 .yrp3d 文件
  config.json         代理模式的设置（对方服务器地址）
  observer.json       观战模式的设置（服务器 / 房间名 / 昵称）

（%APPDATA% 一般就是 C:\Users\你的用户名\AppData\Roaming。
 在窗口工具栏上点「打开录像文件夹」就能直接跳过去。）

录像**故意不放在安装目录里** —— 安装程序升级的时候会先把旧版本整个
删掉再装新的，装在安装目录里的东西会跟着一起没。所以：

  ⚠ **换新版本：直接运行新的安装程序就行。** 它会覆盖安装，
    你的录像和设置都留在原地，不会被删。

  ⚠ **卸载也不会删录像。** 卸载只收走程序本身，上面那三样会留着。
    想彻底清干净的话，卸载完自己把 %APPDATA%\yrp-tools 删掉。

  录像存哪可以改：窗口工具栏上有「更改…」，能指到任意目录
  （D 盘、移动硬盘都行）。换过之后以你选的那个为准。

两个设置文件不用手改，在窗口里填就行。

另外那个文件夹里还会有一些 Cache\、GPUCache\ 之类的东西 ——
那是程序框架自己的缓存，不是你的录像，不用管。

----------------------------------------------------------------
导出
----------------------------------------------------------------

窗口里的「录像」面板可以：

  - 勾选录下来的录像，一次多个
  - 把**本机**的 .yrp3d 录像文件直接拖进窗口（也支持整个文件夹）

然后选一种导出：

  合并 TXT      所有录像的对话拼成一个文件
  分文件 TXT    每个录像一个文件
  JSON          结构化数据，给程序用的
  CSV           表格，Excel 能直接开
  复制全部      复制到剪贴板

点「选择目录」才会问你要存到哪；不选就存到「下载」文件夹。
导出完窗口右下角会给你一个链接，点一下直接用记事本打开。

工具栏的两个勾选框（排除系统消息 / 排除观战发言）对**上面所有格式**都生效。

导出的文件名会自动带上导出时间，不会覆盖上一次的结果。

----------------------------------------------------------------
第一次运行时 Windows 可能拦一下
----------------------------------------------------------------

这个程序没有花钱买数字签名，所以 Windows 可能会弹：

  「Windows 已保护你的电脑」

这时点「更多信息」→「仍要运行」。只会问这一次。
有些杀毒软件也可能误报（它是个自己打包的可执行文件），
加个信任就行。

----------------------------------------------------------------
附带的一个文件：chat-extractor.html
----------------------------------------------------------------

这是一个**单独的网页版**，双击用浏览器打开，把 .yrp3d 录像拖进去就能看和导出。
不需要这个文件夹里的其他任何东西。

它的用处是：**可以单独拷给别人**。
对方什么都不用装，拿到这一个 .html 文件就能看录像、导出对话。

功能和窗口里的一模一样（底下的代码就是同一份），
只是没有录制功能、也不能列出服务器上的录像。

----------------------------------------------------------------
注意
----------------------------------------------------------------

  - 只有 .yrp3d 格式能读。标准 ygopro 的 .yrp 录像**不含对话**，读不了。
  - 观战者的发言会被记录，但默认没有名字（服务器没开这个功能的话，
    名字当初就没写进录像里，补不回来），统一标成「观战者」。
  - 同一局里两个人可能用同一个名字，光看文本分不出谁在说 ——
    窗口里把鼠标停在消息上能看到座位号。
