对话记录 —— 使用说明
================================================================

这是一个录 YGOPro 对局聊天记录的小工具。免安装、不联网上传，
所有文件都在你自己电脑上处理。这个文件夹里没有 Node.js 之类的东西，
**不需要装任何软件**，双击就能用。

----------------------------------------------------------------
先看这里：几个启动文件各是干嘛的
----------------------------------------------------------------

  START.vbs           ← 日常就用这个。打开浏览器界面，没有黑窗口。
                      录、看、导出、把本机录像拖进来，全在这一个页面里。

  proxy.bat           代理模式。你自己下场打牌时用（有黑窗口，能看日志）。
  observer.bat        观战模式。盯着别人的局记录时用，本机不用开客户端。
  gui-console.bat     和 START.vbs 是同一个东西，只是留着黑窗口方便看日志。
                      启动不了的时候用它，报错看得见。

  yrp.exe             ← 【不要双击这个】它是上面四个启动器共用的程序本体。
                      直接双击会弹出一个黑窗口 —— 它是 Node.js 的副本，
                      Windows 一定会给这类程序配窗口，这是正常的。
                      想开界面请点 START.vbs，想用命令行版请点对应的 .bat。
日常流程：双击 START.vbs → 在页面里点「启动代理」或「开始记录」→
打完之后在同一个页面里勾选录像、导出。

服务器地址已经填好了：代理 mygo.superpre.pro:888、观战 mygo2.superpre.pro:888，
第一次打开直接点「启动代理」或「开始记录」就行。要连别的服务器就把它改掉。

----------------------------------------------------------------
录下来的东西在哪
----------------------------------------------------------------

都在本文件所在的文件夹里（第一次运行才会出现）：

  replays\            录好的 .yrp3d 文件
  config.json         代理模式的设置（对方服务器地址）
  observer.json       观战模式的设置（服务器 / 房间名 / 昵称）
  gui-token.txt       界面用的本地口令，自动生成
  gui-url.txt         上次界面的地址，用来实现「再双击一次 = 重开页面」

两个设置文件不用手改，在界面里填就行。

⚠ **不要把这个文件夹放进 C:\Program Files\ 之类的系统目录**，
  放桌面、放 D 盘、放文档里都行。程序要往自己旁边写文件，
  系统目录没有权限，录像和设置就存不下来了。

----------------------------------------------------------------
导出
----------------------------------------------------------------

浏览器界面里的「录像」面板可以：

  - 勾选服务器录下来的录像，一次多个
  - 把**本机**的 .yrp3d 录像文件直接拖进页面（也支持整个文件夹）

然后选一种导出：

  合并 TXT      所有录像的对话拼成一个文件
  分文件 TXT    每个录像一个文件
  JSON          结构化数据，给程序用的
  CSV           表格，Excel 能直接开
  复制全部      复制到剪贴板

工具栏的两个勾选框（排除系统消息 / 排除观战发言）对**上面所有格式**都生效。

导出的文件名会自动带上导出时间，不会覆盖上一次的结果。

----------------------------------------------------------------
第一次运行时 Windows 可能拦一下
----------------------------------------------------------------

这个程序没有花钱买数字签名，所以 Windows 可能会弹：

  「Windows 已保护你的电脑」

这时点「更多信息」→「仍要运行」。只会问这一次。
有些杀毒软件也可能误报（它是个自己打包的可执行文件），
加个信任就行。

----------------------------------------------------------------
附带的一个文件：chat-extractor.html
----------------------------------------------------------------

这是一个**单独的网页版**，双击用浏览器打开，把 .yrp3d 录像拖进去就能看和导出。
不需要这个文件夹里的其他任何东西。

它的用处是：**可以单独拷给别人**。
对方什么都不用装，拿到这一个 .html 文件就能看录像、导出对话。

功能和界面里的一模一样（底下的代码就是同一份），
只是没有录制功能、也不能列出服务器上的录像。

----------------------------------------------------------------
注意
----------------------------------------------------------------

  - 只有 .yrp3d 格式能读。标准 ygopro 的 .yrp 录像**不含对话**，读不了。
  - 观战者的发言会被记录，但默认没有名字（服务器没开这个功能的话，
    名字当初就没写进录像里，补不回来），统一标成「观战者」。
  - 同一局里两个人可能用同一个名字，光看文本分不出谁在说 ——
    界面里把鼠标停在消息上能看到座位号。
